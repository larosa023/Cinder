Steam

Block Steam client updatesKeeps steam.cfg in your Steam folder so the client stays on its current build.
Start Steam in the backgroundLaunches Steam silently with update-blocking flags when Cinder opens.
Keep Steam's window hidden when launching gamesHides Steam's library window and its "Starting game" popup when you launch a game. If a Steam popup is still open after 10 seconds it probably needs you (cloud save conflict, launch options, shader processing), so Cinder shows it again.
Update games from CinderUpdate buttons and download pause/resume go through Steam's own interface, so no Steam window opens. The first time you use it, Steam restarts once in the background. This switches on Steam's local debugging connection, which only programs on this PC can reach.

Cinder never asks for your Steam password. Buying, chat and wishlist changes open in the real Steam client.
